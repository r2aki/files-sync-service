# Сервис синхронизации файлов

## Описание

Этот проект представляет собой простой Python-скрипт для синхронизации файлов между локальной папкой на вашем компьютере и облачным хранилищем [Яндекс.Диск](https://disk.yandex.ru/).

Программа запускается в фоновом режиме, отслеживает изменения (создание, изменение, удаление) в указанной локальной папке и автоматически применяет соответствующие изменения (загрузка, обновление, удаление) в связанной папке на Яндекс.Диске. Это обеспечивает автоматическое резервное копирование важных файлов.

## Функциональность

*   **Синхронизация файлов:** Автоматически загружает новые и изменённые файлы из локальной папки в облако.
*   **Удаление файлов:** Если файл удаляется из локальной папки, он также удаляется из облака.
*   **Конфигурирование:** Параметры (путь к папке, токен, интервал синхронизации) задаются в файле `config.ini`.
*   **Логирование:** Все действия и ошибки записываются в лог-файл.
*   **Обработка ошибок:** Ошибки при работе с файлами или сетью не прерывают работу программы.
*   **Модульность:** Логика работы с Яндекс.Диском вынесена в отдельный класс для потенциального расширения на другие облачные сервисы.

## Требования

*   Python 3.6 или выше
*   Библиотека `requests` (устанавливается через `pip`)

## Установка и настройка

1.  **Клонируйте репозиторий (или скачайте архив):**
    ```bash
    git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
    cd <НАЗВАНИЕ_ПАПКИ_ПРОЕКТА>
    ```

2.  **Установите зависимости:**
    ```bash
    pip install requests
    ```

3.  **Получите токен Яндекс.Диска:**
    *   Перейдите на [официальную страницу для работы с API](https://yandex.ru/dev/disk/poligon/).
    *   Авторизуйтесь под своей учётной записью Яндекс.
    *   Найдите раздел "OAuth" или "Получить OAuth-токен".
    *   Следуйте инструкциям для генерации персонального токена доступа.
    *   **ВНИМАНИЕ:** Этот токен предоставляет доступ к вашему Яндекс.Диску. Храните его в секрете.

4.  **Настройте `config.ini`:**
    *   Откройте файл `config.ini` в текстовом редакторе.
    *   Измените значения параметров под свои:
        *   `local_folder`: Полный путь к локальной папке, которую вы хотите синхронизировать. Пример: `C:\Users\YourName\Documents\BackupFolder` (Windows) или `/home/yourname/backup` (Linux/Mac).
        *   `cloud_folder`: Путь к папке на Яндекс.Диске, которая будет использоваться для хранения файлов. Программа создаст её, если она не существует. Пример: `/app_folder/backup`. Обязательно начинайте с `/`.
        *   `token`: Вставьте сюда полученный на предыдущем шаге токен доступа.
        *   **ВАЖНО:** Удалите или обнулите токен в файле `config.ini` перед тем, как делиться кодом (например, при сдаче задания или публикации в репозитории).
        *   `sync_interval`: Интервал проверки изменений в секундах (например, `60` для проверки раз в минуту).
        *   `log_file`: Имя файла, куда будут записываться логи (например, `sync.log`).

    **Пример `config.ini`:**
    ```ini
    [settings]
    local_folder = C:\path\to\your\local\folder
    cloud_folder = /app_folder/backup
    token = YOUR_ACTUAL_YANDEX_DISK_TOKEN_HERE
    sync_interval = 60
    log_file = sync.log
    ```
